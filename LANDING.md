# SensecraftXStudio Landing Page

Static, dependency-free landing page prepared for GitHub Pages.

## Files

- `index.html` — semantic page structure and copy
- `styles.css` — visual system, responsive layout, accessibility states
- `script.js` — mobile navigation, copy action, subtle progressive reveal
- `assets/banner.png` — existing repository identity asset
- `AGENTS.md`, `README.md`, `LICENSE` — original repository files used by page links

## Local preview

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## GitHub Pages

Publish this directory from the root of the target branch, or copy the three landing files and existing `assets/` folder into the branch root.
